# Sleep Health 条件概率分布对比报告

数据源：`public/data/Sleep_Health_and_Lifestyle_Dataset.csv`，本地 CSV 共 374 条记录。项目 README 与 Kaggle 数据页指向：<https://www.kaggle.com/datasets/adilshamim8/sleep-cycle-and-productivity>。

计算口径：

- 数据集实证矩阵：直接使用 `Pr(A|S)=count(S,A)/count(S)`。
- 大数据库假设矩阵：使用对称 Dirichlet(1) / Laplace 平滑，即 `(count(S,A)+1)/(count(S)+K)`，其中 `K` 是该属性的候选类别数。它不是编造分布，而是在当前公开数据集计数基础上做总体概率的稳健估计。
- 年龄段：青年 18-44 岁，中年 45-59 岁，老年 60 岁及以上。当前 CSV 中老年样本数为 0，因此老年行不做估计。
- 睡眠异常状态：`Sleep Disorder=None` 记为 `正常(M=0)`，其他值如 `Insomnia`、`Sleep Apnea` 记为 `异常(M=1)`。
- 身体活动水平分档：`Physical Activity Level < 40` 为低活动，`40-59` 为中低活动，`60-74` 为中高活动，`>=75` 为高活动。
- 睡眠质量评分：原始 `Quality of Sleep` 为 1-10 分；这里按当前项目 TSP 的 1-5 值域使用 `ceil(score/2)` 映射。

## 对比结论

- 对样本数较大的行，平滑矩阵与实证矩阵非常接近，例如青年睡眠异常率从 29.20% 调整为 29.37%，中年睡眠异常率从 66.13% 调整为 65.87%。
- 对小样本行，平滑影响明显，例如肥胖组只有 10 条记录，每日步数实证矩阵显示 2000-3999 为 100%，但大数据库假设矩阵将其调整为 61.11%，其余桶各为 5.56%。这避免把小样本中的偶然零频率当成总体中绝对不可能。
- 超重组身体活动的中高活动实证频率为 0.00%，平滑后为 0.66%。这类调整更适合作为“总体数据库足够大时”的稳健估计。
- 老年组没有样本，不能凭空构造条件分布；报告中保留为 N/A。
